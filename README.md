# Драфт — сценарный редактор

Русскоязычный аналог Final Draft для сценарных групп: строгий мировой формат страницы (Courier 12, отступы элементов, 1 страница ≈ 1 минута), подсказки имён персонажей и объектов, хронометраж, процент объектов и павильона, проверка производственных параметров студии, комментарии продюсера, драфты, библия персонажей и экспорт, который без правок читает FilmToolz и Final Draft.

Прототип работает целиком в браузере и не требует сервера: данные хранятся в IndexedDB. Следующий этап — облачная версия с общей базой, ролями и резервными копиями (см. `docs/`).

## Состав

| Путь | Что это |
|---|---|
| `app/index.html` | разметка интерфейса |
| `app/styles.css` | стили, светлая и тёмная тема, геометрия страницы |
| `app/core.js` | «ядро» без DOM: формат и пагинация, разбор заголовков, анализ серии, правила студии, импорт (FDX, Word, PDF, текст), экспорт (FDX, Word для FilmToolz, Fountain), история и откат. Работает и в Node |
| `app/app.js` | интерфейс: редактор, панели, автодополнение, комментарии, драфты, история, корзина, настройки |
| `app/fonts.js` | встроенный шрифт FreeMono (латиница + кириллица) для PDF и для машин без Courier New |
| `build.py` | собирает `app/_test.html` для тестов и один автономный файл `dist/Драфт.html` |
| `tests/` | модульные тесты ядра (`test_core.js`, `test_docx.js`, `test_pdf.js`, `test_lines.js`) и сценарии Playwright (`test1.js` … `test11.js`) |
| `docs/` | ссылки на спецификацию и документ о сохранности |

## Запуск

```bash
npm install            # библиотеки для тестов; сам редактор ничего не требует
npm run build          # dist/Драфт.html — один файл, открывается двойным щелчком
npm test               # тесты ядра
npm run test:ui        # сборка + сценарии в безголовом Chromium
```

Во время работы редактор подгружает из cdnjs три библиотеки: jszip (Word), jspdf (PDF-экспорт) и pdf.js (PDF-импорт). Без интернета всё остальное работает.

## Образцы сценариев

Реальные сценарии студии (`samples/`) в репозиторий не кладутся: репозиторий открытый. Тесты импорта (`test6`, `test7`, `test9`, `test_docx`, `test_lines`) ждут файлы `samples/treshka.docx`, `samples/ies51.pdf` и распакованный `samples/x/word/` локально.

## Формат

За образец взят Final Draft: Letter, поля 1" сверху/снизу/справа и 1,5" слева, Courier 12, 54 строки на странице. Отступы элементов от края листа: сцена и описание 1,5", персонаж 3,5", ремарка 3,0", реплика 2,5", переход 5,5"–7,1" (вправо). Диалог на разрыве страницы получает (ДАЛЬШЕ) и (ПРОД.). Есть вариант A4 на 58 строк.

## Драфты (ревизии) и лок страниц

Механика ревизий Final Draft, но без цветов: студия называет версии по номерам (Производство → «Драфты: новый драфт и пометки…»). Исходный текст — «Драфт 1». Продюсер или редактор начинает следующий драфт: «Драфт 2», «Драфт 3» и так далее. Законченный драфт при этом сохраняется под своим номером в списке драфтов серии. Каждый драфт хранит копию текста на момент начала (`ep.revisions[]`: уровень, дата, кто начал, база); текущий — в `ep.revLevel` (уровень 0 = «Драфт 1», уровень n = «Драфт n+1»). Ручное «Сохранить версию драфта» предлагает имя «Драфт 3, версия 1».

- Всё, что изменилось относительно предыдущего драфта (новый элемент, другой текст, другой тип, перенесённый текст — например, сцена, сдвинутая кнопками ↑/↓, — а также элемент сразу после удалённого текста), помечается звёздочкой «*» на правом поле. Пометки текущего драфта выделены, пометки прошлых драфтов серые. Элемент держит самый поздний драфт, в котором менялся. Пометки на экране включаются галочкой «Показывать пометки», в строке состояния виден текущий драфт.
- PDF: звёздочки на 7,6" (на A4 — внутри листа), на изменённых страницах шапка «Драфт 2 — 01.11.2026», номер драфта на титуле; цветных полос нет. Опция «Только изменённые страницы» печатает титул, страницы с пометками текущего драфта под их прежними номерами и A-страницы сразу за ними (на них уходит текст, вытесненный с залоченной страницы).
- Лок страниц: после него каждая страница начинается с того же элемента. Текст, который не помещается, уходит на A-страницы (12A, 12B), укоротившаяся страница остаётся короткой. Удаление в конце залоченной страницы помечается на ней самой, а не на следующей; страница, с которой удалён весь текст, входит в номер предыдущей («2-3», как в Final Draft), и та уходит в замену. «УДАЛЕНА» остаётся на странице, где была сцена, и помечена только она. Номера одинаковы на экране, в PDF и в .fdx (страница сцены). Хронометраж считается по тексту, а не по коротким страницам. Снятие лока спрашивает причину и пишется в историю (`ep.pageLockLog`).
- .fdx: `<Revisions>` с наборами «Драфт N» и `RevisionID` на изменённых абзацах (Final Draft требует цвет у набора, поэтому в файл пишутся цвета WGA; в самом Драфте их не видно). При загрузке .fdx пометки Final Draft становятся драфтами серии с номерами; начатая в Final Draft ревизия без единой пометки тоже сохраняется. Даты наборов .fdx не хранит: после загрузки у драфтов дата загрузки.
- Номер драфта и лок страниц путешествуют вместе с текстом: Ctrl+Z, драфты и история возвращают их в том состоянии, в каком был текст. Исключение — сценарист: восстановленный им драфт или снимок истории возвращает только текст, лок страниц и номер драфта остаются (менять их может редактор или продюсер). Если лок снимает восстановление, сделанное редактором или продюсером, это пишется в `ep.pageLockLog` с причиной «восстановлен драфт …».

## Разбивка сценария

Как Tagger в Final Draft и разбивка в Movie Magic. Выделите в тексте то, что нужно для съёмки, и выберите категорию: Производство → «Пометить для разбивки…» (**Ctrl+Alt+T**) или кнопка «Разбивка» на панели инструментов. Цифры 1–9 выбирают категорию, можно добавить примечание. Категории: Реквизит, Костюм, Грим, Транспорт, Массовка, Трюки, Животные, Спецэффекты, Звук/музыка, Оружие, Декорация, Персонаж-эпизод — у каждой свой цвет.

- Пометки хранятся в серии (`ep.tags`: id, элемент, цитата, категория, примечание) и привязаны к тексту так же, как комментарии: правка, разбиение и склейка элементов их не теряют, а повторённое в элементе слово сохраняет свою пометку и после правок перед ним. Пометка переходит только вместе со своим текстом и не дальше своей сцены: если слово удалено или переписано, она не перескакивает на то же слово в соседней сцене, а ждёт возвращения текста (Ctrl+Z, драфт, «Вернуть сцену») и видна во вкладке «Разбивка» как «Текст удалён». Вырезанный (Ctrl+X) и вставленный в другом месте текст забирает свои пометки с собой.
- Вид → «Разметка разбивки» подчёркивает помеченный текст цветом категории (по умолчанию выключено, страница остаётся чистой). Щелчок по пометке показывает её и кнопку «Убрать».
- Карточка сцены показывает её разбивку; вкладка «Разбивка» справа — всю серию по категориям с номерами сцен (щелчок — переход к сцене) и сводку по объектам.
- Трюки и животные из разбивки делают сцену особой для параметров студии (выработка ÷2,5), как метки сцены; сцена с меткой и пометкой считается один раз. В списке сцен такая метка обведена пунктиром.
- Экспорт «Разбивка в Excel (.xlsx)» (Файл → Экспорт и вкладка «Разбивка»): листы «Сцены» (номер, заголовок, объект, режим, ИНТ/НАТ/ПАВ, сценарный день, страницы в восьмых, хронометраж, персонажи, массовка и столбец на каждую категорию), «Объекты», «Персонажи», «Разбивка».
- Помечают сценарист, редактор и продюсер; читатель только смотрит. Пометки входят в Ctrl+Z, драфты и историю (продюсер, который не ставит курсор в текст, тоже отменяет пометку Ctrl+Z); при открытии файла проекта пометки обеих копий объединяются, убранные с любой стороны не возвращаются.

## Сайды

Сцены съёмочного дня для актёров и группы, как «Print selected scenes» в Final Draft (Производство → «Сайды…»).

- Отметьте сцены в списке (номер, заголовок, страницы) или быстрым выбором: «Сцены персонажа» отмечает все сцены, где он говорит или упомянут, «По сценарному дню» — сцены одного дня. Впишите получателей по одному в строке, срок (по умолчанию +3 дня) и пометку для шапки («Съёмочный день 12»).
- На каждого получателя — свой PDF (или все экземпляры одним файлом). В нём только отмеченные сцены по порядку сценария, в формате Final Draft, с номерами сцен с обеих сторон и пометками ревизий; невыбранные сцены пропущены целиком, титула нет. На каждой странице: шапка «Сайды · пометка · стр. N» (на странице с изменениями под ней отдельной строкой — название ревизии), имя получателя по диагонали, колонтитул «Экземпляр: имя · действительно до дата» и гриф коммерческой тайны.
- Срок не может быть в прошлом. Каждый выданный экземпляр пишется в журнал проекта (`project.sidesLog`: кто выдал, роль, кому, серия, номера сцен, пометка, срок); экземпляр, файл которого не сохранён (сохранение отменено или не удалось), в журнал не попадает. Журнал виден в том же окне, истёкшие отмечены. Журнал входит в файл проекта и при открытии файла объединяется с локальным.
- Выдают только редактор и продюсер; сценарист и читатель видят журнал.
- Срок лишь напечатан на экземпляре: PDF не перестанет открываться сам. Журнал фиксирует выдачу, а не просмотр или пересылку.
