# Драфт — сценарный редактор

Русскоязычный аналог Final Draft для сценарных групп: строгий мировой формат страницы (Courier 12, отступы элементов, 1 страница ≈ 1 минута), подсказки имён персонажей и объектов, хронометраж, процент объектов и павильона, проверка производственных параметров студии, комментарии продюсера, драфты, библия персонажей и экспорт, который без правок читает FilmToolz и Final Draft.

Прототип работает целиком в браузере и не требует сервера: данные хранятся в IndexedDB. Следующий этап — облачная версия с общей базой, ролями и резервными копиями (см. `docs/`).

## Состав

| Путь | Что это |
|---|---|
| `app/index.html` | разметка интерфейса |
| `app/styles.css` | стили, светлая и тёмная тема, геометрия страницы |
| `app/core.js` | «ядро» без DOM: формат и пагинация, разбор заголовков, анализ серии, правила студии, импорт (FDX, Word, PDF, текст), экспорт (FDX, Word для FilmToolz, Fountain), история и откат. Работает и в Node |
| `app/app.js` | интерфейс: редактор, панели, автодополнение, комментарии, драфты, история, корзина, настройки |
| `app/fonts.js` | встроенный шрифт FreeMono (латиница + кириллица) для PDF и для машин без Courier New |
| `build.py` | собирает `app/_test.html` для тестов и один автономный файл `dist/Драфт.html` |
| `tests/` | модульные тесты ядра (`test_core.js`, `test_docx.js`, `test_pdf.js`, `test_lines.js`) и сценарии Playwright (`test1.js` … `test11.js`) |
| `docs/` | ссылки на спецификацию и документ о сохранности |

## Запуск

```bash
npm install            # библиотеки для тестов; сам редактор ничего не требует
npm run build          # dist/Драфт.html — один файл, открывается двойным щелчком
npm test               # тесты ядра
npm run test:ui        # сборка + сценарии в безголовом Chromium
```

Во время работы редактор подгружает из cdnjs три библиотеки: jszip (Word), jspdf (PDF-экспорт) и pdf.js (PDF-импорт). Без интернета всё остальное работает.

## Образцы сценариев

Реальные сценарии студии (`samples/`) в репозиторий не кладутся: репозиторий открытый. Тесты импорта (`test6`, `test7`, `test9`, `test_docx`, `test_lines`) ждут файлы `samples/treshka.docx`, `samples/ies51.pdf` и распакованный `samples/x/word/` локально.

## Формат

За образец взят Final Draft: Letter, поля 1" сверху/снизу/справа и 1,5" слева, Courier 12, 54 строки на странице. Отступы элементов от края листа: сцена и описание 1,5", персонаж 3,7", ремарка 3,1", реплика 2,5", переход 5,5" (вправо). Диалог на разрыве страницы получает (ДАЛЬШЕ) и (ПРОД.). Есть вариант A4 на 58 строк.
